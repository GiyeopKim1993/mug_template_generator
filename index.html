    • 템플릿 크기 선택 (기본 205 × 87 mm, 인치 기원 템플릿도 선택 가능)
    • 이미지 업로드 → 2D 편집기에서 드래그/휠로 위치·크기·회전 지정 (3D 미리보기에 바로 반영) · 내보내기 시 저장 패널이 열립니다 · 일괄 내보내기는 합본 PDF (A4) · 앞면/뒷면 가이드(파란 점선, 인쇄 안 됨) — 왼쪽·가운데·오른쪽 3곳 스냅(2.5mm 안으로 끌면 자동 스냅 + “왼쪽/앞면/오른쪽 정렬 ✓”), 뒷면·핸들=양쪽 가장자리(템플릿 노치/라벨 위치)
    • 3D 뷰: 드래그=회전(상하=고도) · Shift/우클릭 드래그=화면 이동 · Ctrl 드래그=좌우 기울임 · 휠=줌 · 더블클릭=뷰 리셋 · 턴테이블=자동 360° 회전(속도 선택 가능, 드래그해서 놓으면 관성 회전)
    • 내보내기 다이얼로그(상단·우측 레일 버튼 또는 Ctrl/⌘+P) — 범위(현재 디자인/목록 전체)·모드·마크·배치를 왼쪽에서, 미리보기·PDF/DXF 내보내기를 오른쪽/하단에서 · 용지는 A4 전용 · 100% 크기로 인쇄
    • 디자인·레이어: 이미지는 레이어로 쌓입니다 — 목록에서 순서 바꾸기(▲▼)·보이기/숨기기·삭제·선택, 정렬 버튼 6개(좌/가운데/우·상/중앙/하)로 템플릿에 맞춤. +새 디자인으로 시트를 따로 만들고, 배치가 2개 이상이면 배치별 디자인으로 서로 다른 디자인을 한 페이지에 섞어 인쇄할 수 있습니다 (같은 것도 여러 개, 다른 것도 여러 개)
    • 작업창·렌더링·임시저장: 오른쪽 렌더링 창 클릭 = 모달에서 크게 보기 (더블클릭은 취소+뷰 리셋, ESC/바깥 클릭으로 닫기) · 레이어 Shift+클릭으로 복수 선택 후 정렬 → 그룹 기준 정렬 · 크롭 버튼으로 영역 잘라내기(적용/취소) · 레이어 W 버튼(기본 ON)으로 흰색을 투명 처리해 인쇄 불가 W 제거 · 임시 저장 버튼으로 쌓아두고 전체 내보내기 → 내보내기 창의 범위=목록 전체로 합본 PDF 한 번에 저장 (ZIP 없음 · 미리보기에서 쪽 확인)

    인쇄 요령

    • 스케일은 반드시 100% (실제 크기). “맞춤/페이지에 맞게”는 크기가 어긋납니다.
    • 미러(좌우 반전) ON: 서브리메이션 전사 인쇄용 — 전사지는 도면을 뒤집어 붙이므로 반전해서 인쇄해야 머그에 정방향으로 나옵니다. 이미지가 이미 반전된 파일이면 체크를 해제하세요.
    • 용지: 기본 A4 (실루엣/스캔앤컷 인터넷 A4 마크 템플릿과 동일 배치 · US Letter도 선택 가능) · 양면 아님 · 고품질 사진/서브리메이션 용지 권장
    • 템플릿 모양: 실제 11oz 풀랩처럼 양쪽 짧은 가장자리에 핸들 노치(반원 컷아웃)가 있습니다. 머그press용 평판이 필요하면 노치를 해제하세요.

    모드 1 — 재단선 포함 (가위/재단기용)

    • 템플릿 외곽선(노치 포함)을 따라 0.15pt 페일 시안 절취선이 인쇄됩니다(거의 보이지 않는 색).
    • 배치(중복 인쇄): 재단선 모드는 가로 최대 3개 / 세로 최대 2개까지 한 페이지에 배치됩니다.
    • 재단선 바깥의 안내문은 잘라내면 사라지는 여백용 텍스트입니다.
    • 종이 재단기(트리머)로 선을 따라 재단 → 전사 테이프로 머그에 고정.

    모드 2 — 인식 마크만 인쇄 (절취선 없음)

    • 실루엣 (Silhouette Type 1): 좌상단 사각 마크 + 우상단·좌하단 L자 마크 — 공식 Silhouette Connect 매뉴얼의 도면에서 이미지로 추출 PDF의 별도 레이어(OCG)로 배치했습니다 (임의 그리기 아님). Studio 기본값 준수: 인셋 15.875mm · 길이 20mm · 두께 0.99mm(0.039″), 용지 A4 Studio에서 페이지 설정 → 등록 마크 → Type 1, A4를 맞춘 뒤 재단 사각형을 그리면 컷 데이터가 됩니다. (PDF는 마크와 도면만 인쇄)
    • 브라더 스캔앤컷 DX (Print to Cut): 네 모서리 타깃(동심원+바) 마크 — 공식 Brother ScanNCut Link 매뉴얼 다이어그램에서 이미지로 추출 별도 레이어로 배치했습니다. 용지 A4 CanvasWorkspace에서 Artboard Size = A4 + Show Registration Mark를 켜고 재단 사각형(= 템플릿 크기)을 그려 FCM으로 전송하세요. 배치가 조금 다를 경우를 대비해 마크 위치 오차가 있으면 기기의 스캔(직접 컷) 기능을 쓰세요.
    • 이 모드에서는 절취선을 인쇄하지 않습니다 — 대신 DXF 내보내기로 컷 외곽 벡터 파일을 받아 실루엣 스튜디오/브라더 캔버스에 그대로 불러오세요 (레이어 불필요, mm 단위, 페이지 좌표 일치).
    • 이 모드의 배치는 세로만 가능하며 병렬 최대 2개까지 배치됩니다.
    • 선택한 개수가 인식 마크 영역과 겹치면 자동으로 개수를 줄이고 안내합니다 (가능한 크기에서는 2개 그대로).
      • 재단 경계는 인쇄된 디자인 가장자리(배경색 경계)를 보고 재단하거나, 컷 데이터의 사각형을 따릅니다. 배경을 흰색으로 두면 경계가 보이지 않니 배경색을 지정하는 편이 재단하기 쉽습니다.
    • 마크는 검정으로 또렷해야 인식됩니다. 광택/색이 있는 용지에는 인식이 어려울 수 있습니다.

    튜닝 팁

    • 머그/프린터마다 오차가 있으니, 첫 시안을 재단해서 실측 → “사용자 지정” 크기로 보정하세요.
    • 재단선 색은 “아주 옅게 → 옅게 → 보통” 중 출력 결과에 맞게 고르면 됩니다.
