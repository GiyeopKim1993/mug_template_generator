🎯 트리거 (언제 광고를 보여줄지)

쿨다운은 트리거마다 24시간. 아래 설정 저장에서 version을 올리면 해제·쿨다운 상태가 초기화되어 다시 뜹니다.

🔑 후원자 코드 (광고 없이 트리거 해제)

발급 즉시 config의 해시 목록에 저장 — 코드 원문은 지금 한 번만 표시됩니다
발급된 코드 (지금 바로 복사·전달):
후원자: 사이트 푸터의 🔓 후원자 코드 버튼에 입력 → 광고 트리거 영구 해제. SHA-256 해시만 저장되므로 원문 유출 위험이 없습니다. 해제(삭제)하려면 목록에서 X.

📖 광고 넣는 법 & 정산 요약

1) 애드센스 (단가 높음, 해외+국내 광고)
adsense.google.com 가입 → 사이트 심사(콘텐츠·도메인) → 「광고 단위」 생성 → <script> 코드2줄 복사 → 이 페이지의 광고 슬롯에 붙여넣기 + 체크 → 저장 → git push
정산: PIN 인증($10 도착 시 우편) → 세금정보(W-8BEN) → 본인 계좌 등록 → $100 이상이면 매월 21~26일 자동 해외송금(원화계좌 가능, 송금수수료 5~10$ 차감) · 미달 시 이월

2) 애드핏 (국내, 승인 쉬움)
adfit.kakao.com → 매체(사이트 URL) 등록 → 광고단위 생성 → 스크립트 복사 → 같은 방식으로 저장·push
정산: 월 수익 → 익월 1일 정산 시작 → 15일 입금 · 소득세·지방세 원천징수 3.3% 자동(개인명의 신고)

트리거 광고는 코드가 붙어야 실제 광고가 뜹니다 (없을 때는 후원 안내 문구). 확인은 사이트 주소 뒤에 ?ad=1 · 실측상 애드센스 단가 > 애드핏이며, 수익 = 노출×클릭률×단가.
