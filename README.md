# 11oz 머그컵 템플릿 메이커

브라우저에서만 동작하는 단일 파일 웹앱입니다 (서버·전송 없음). `index.html` 하나로 끝납니다.

- **작업창 + 우측 레일 레이아웃** — 좌: 큰 작업창(2D 편집 · 템플릿 · 디자인/정렬/크롭) / 우: 레일(작은 렌더링 창 → 레이어 → 출력설정) — 1280px 미만 레일 360px, 980px 미만 단일 컬럼
- **렌더링 창 클릭 = 확대 모달** — 레일 상단의 작은 3D 렌더링을 클릭하면 모달에서 크게 보기 (더블클릭은 취소+뷰 리셋, ESC/바깥 클릭으로 닫기)
- **임시 저장 + 일괄 내보내기(배치 모달)** — 스냅샷(디자인·레이어·설정·썸네일) 목록에서 불러오기/삭제/개별 PDF · 「전체 내보내기」→ 모달에서 방식 선택: **① 합본 PDF**(임시 저장들을 세로 90° 재배치한 단일 PDF — **실루엣 Type1 / 브라더 스캔앤컷 DX 등록 마크와 용지(A4/Letter)를 내보낼 때 선택**, 각 작업의 디자인·미러는 각자 설정 유지) 또는 **② 개별 PDF → 단일 ZIP**(`-s1/-s2`, 여러 파일 다운로드 차단 회피)
- **미리보기(iframe)에서도 실제로 저장된다** — sandbox 프레임은 `<a download>`를 **사용자 클릭조차** 차단하고 **File System Access API도 거부**(`Sandboxed documents aren't allowed to show a file picker`) → 내보내기 시 **저장 패널** 자동: 주소창 자동 선택 + **새 창으로 열기** 버튼(팝업 허용 시 즉시 성공) + 주소 복사→새 탭 붙여넣기 + 미리보기 툴바 💾/우클릭 저장 + **버튼을 폴더로 드래그** + DXF 내용 복사 · 최상위 탭은 기존처럼 즉시 다운로드(토스트도 정직하게)
- **멀티 선택 그룹 정렬** — 레이어 Shift/Ctrl+클릭으로 복수 선택 후 정렬 버튼 6개 → 그룹 bbox 기준 정렬 (선택 1개면 기존대로 템플릿 기준)
- **알파 = 원본 투명부만** — 화이트 키링 제거(개정 2026-10-05): CMYK(0,0,0,0) 순백은 유효 데이터로 불투명 유지, 소스에 데이터 없는(투명) 영역만 알파
- **이미지 크롭** — ✂ 크롭으로 사각형 영역 잘라내기(적용/취소, 회전 인식 중심 보정)
- **출력 설정 = 인쇄 다이얼로그(⌘P)** — 일러스트레이터 프린트 창처럼: 왼쪽 옵션(모드·용지·마크·배치 접이식) / 오른쪽 미리보기 / 하단 PDF·DXF 내보내기 — 오른쪽 레일에는 요약 탭 + 「인쇄 설정…」 버튼만 상주 · `Ctrl/⌘+P`로 열기 · ESC로 닫기
- **좌측 아이콘 툴바 + 변형 컨트롤바** — 업로드/채우기(`F`)/가운데/크롭(`C`)/삭제(`Del`)·배경색 스와치를 캔버스 왼쪽 세로 툴바로, **X/Y/W/∠ 수치 입력 + 정렬 6버튼**을 캔버스 상단 컨트롤바로 (Illustrator 스타일)

- 3D 머그 미리보기 — 9축 자유 조작: 드래그=회전(요/고도) · Shift·우클릭 드래그=화면 이동 · Ctrl 드래그=좌우 기울임 · 휠=줌(Z/스케일) · 더블클릭=뷰 리셋 · 드래그 후 놓으면 관성 회전
- 3D 턴테이블: 자동 360° 회전(느리게/보통/빠름 선택) — 서브리메이션 전사 느낌을 위해 밴드 가장자리가 원통 곡률을 따라 휘고, 유약 하이라이트/음영이 전사면 위에 한 겹으로 덮음
- **3D 정면 핸들·가로줄 수정 (빌드 v4.9)** — 기본 뷰가 핸들 정면(손잡이를 향함)일 때 ① 손잡이를 얇은 아웃라인 선이 아니라 **입체 루프**(도자기 톤 채움 + 접촉 그림자, 바깥/안쪽 곡선만 스트로크, 몸체에 닿는 코드는 생략)로 렌더 → 「짤림·C자 외곽선」 제거 ② 상단 앰비언트 + 하단 AO **4개 rect 그라디언트를 1개로 병합** → 몸체를 가로지르던 경계선(가로줄) 제거 ③ 미세 **디더링**으로 GPU 8비트 그라디언트 밴딩 억제 · 푸터 + **3D 화면 좌하단 칩에 빌드 v4.9 표기**(스크린샷만으로 빌드 확인 가능 — 칩은 캔버스 전용이라 인쇄/PDF에 안 나감)
- 2D 편집기 (드래그=이동, 휠=크기, 코너 핸들=리사이즈)
- 이미지 업로드 / 드래그앤드롭 / Ctrl+V 붙여넣기
- 실제 11oz 풀랩 **템플릿 형상**: 양쪽 짧은 가장자리에 핸들 노치(반원 컷아웃) — 노치 해제 체크박스로 평판도 가능
- 출력 모드
  1. **재단선 포함** — 템플릿 외곽선(노치 포함)을 **0.12~0.18pt 초미세 + 페일 시안**(애초에 잘 보이지 않는 색)으로 인쇄 — 옅게/보통 3단계
  2. **인식 마크만** — 실루엣 Type 1 / 브라더 스캔앤컷 마크만 인쇄, 절취선 없음
- **가이드라인 레퍼런스 재현** — 편집기 템플릿에 **왼쪽/오른쪽 점선 구역 박스 + 가운데 ‘앞면 중심’ 세로선 + 가로 중심선** 항상 표시(이미지 없어도) — 옛 구현의 ‘흰 종이 위 흰 선’(무색)·‘이미지 있을 때만 표시’ 두 결함 수정 · 인쇄/PDF/3D엔 절대 안 나감
- **디자인(시트)·레이어** — 포토샵식: 이미지 레이어 스택(순서 ▲▼, 보이기/숨기기, 삭제, 선택) + 6방향 정렬(템플릿 기준, 회전 bbox 인식) · 디자인 시트를 여러 개 만들어 각각 독립 편집
- **배치(중복 인쇄)** — 재단선 모드: 가로·세로 선택, **가로 최대 3개(세로 스택) / 세로 최대 2개(병렬)** · 인식 마크 모드: **세로만, 최대 2개** (자동/가로 선택 비활성) · **배치별 디자인 매핑**으로 같은 것 여러 개 + 서로 다른 것 여러 개 혼합 가능 · 마크 영역과 겹치면 개수 자동1개 폴백+안내
- **마크 배치 판정 = 실제 규칙** — 인식 마크 주변 영역만 회피 + 용지 5mm 여유 (안전 박스 기준 규칙 완화로 가능한 조합 증가)
- **3D 뷰 클램프** — 확대 상한(전체가 화면에 들어오는 수준) + 이동(팬)/롤/시점 변경 시에도 머그(전사면)가 화면 밖으로 잘리지 않음
- **DXF 내보내기** — 인식 마크 모드에서 전용 버튼: 노치 포함 컷 외곽을 LINE/ARC 벡터(R12, mm 단위, 페이지 좌표 Y-up)로 저장 → Silhouette Studio / Brother Canvas Workspace에서 그대로 불러오기
- 용지: 전 모드 기본 **A4** (인터넷의 실루엣/스캔앤컷 A4 마크 템플릿과 동일 배치 · US Letter 선택 가능)
- 세로/가로 배치 전환 시 이미지는 **실제 90° 회전** (늘이지 않음)
- 미러(좌우 반전) 인쇄 지원, 100% 실제 크기 PDF 내보내기
- **앞면/뒷면 가이드 (인쇄 안 됨)** — 2D 편집기 전용 파란 점선: **앞면 중심선은 항상 표시**(안 보일 때 어두움 → 스냅 시 밝아짐 + "앞면 정렬 ✓" 배지 + "앞면 중심" 라벨): **앞면=가운데**(템플릿 양쪽 "핸들·이음매" 라벨의 정중앙, 2.5mm 스냅) · **뒷면·핸들=양쪽 가장자리**(노치/라벨 위치) · 이미지 중심 틸 크로스헤어 · 드래그 중 ΔX·ΔY 표시 · 인쇄/PDF/DXF/3D 전부 미포함 (test/guides_test.py)
- **기본 업로드 = 전체 보기(CONTAIN)** — 세로/가로가 긴 이미지도 머그에 **통째로** 전사(구 커버 방식은 높은 이미지를 가로 띠로 잘라 "긴 줄/줄무늬"처럼 보였던 원인) · F(면에 채우기)는 그대로 커버 · 템플릿보다 커지는 순간 "일부만 전사됩니다" 토스트

## 인식 마크 출처 (임의 그리기 아님)

- **실루엣 Type 1**: 공식 *Silhouette Connect* 매뉴얼 9페이지 Type 1 도면에서 마크(좌상단 사각 + 우상단 ⌐ + 좌하단 L)를 이미지로 추출 → PDF에 별도 OCG 레이어로 배치. 기본값: 인셋 15.875mm, 길이 20mm, 두께 0.99mm(0.039″).
- **브라더 스캔앤컷**: 공식 *Brother ScanNCut Link* 매뉴얼 다이어그램에서 타깃 마크(동심원+상단 바)를 이미지로 추출 → 별도 OCG 레이어로 배치, 인셋 25.4mm. A4 아트보드 기준(공식 매뉴얼 예시도 A4).
- 노치 치수: 실제 11oz/15oz 템플릿 이미지 측정 — 반원 반지름 = 높이의 8%, 중심 = 높이의 20%/80%.
